# SportsWise · 找到自己的运动节奏

从你的运动现状、目标和生活安排出发，制定第一周试行计划；根据反馈调整，在日、周、月的跟进中逐渐认识自己、建立规律。

已部署：[sportswise.waywise.tech](https://sportswise.waywise.tech)。本地地址 http://127.0.0.1:8500。开发数据库和凭据不进入版本控制；线上使用独立服务与数据库。

## 已实现

- 手机与桌面适配的「今天 / 计划 / 成长 / 我的」，从零试用与含四周虚构记录的示例空间相互独立。
- 邮箱验证码登录；本机开发且未配置 SMTP 时，仅本机请求返回开发验证码，生产环境不开放此回退。
- 自然语言整理档案后逐项核对，目标、现状、兴趣、器械、可用日期与时间、身体限制。
- 基础体能路线：轻松步行、室内活动和有限的自重力量动作。初始时长按起点限制，不把可用时间直接等同于适合训练量。
- 中文对话修改和快捷修改：缩短、本周减量、室内替换、周内改期、休息、重新开始；草案预览、用户采用、版本和撤回。
- 实际训练计时、完成 / 部分完成 / 未完成 / 休息反馈，自主活动记录，重复提交按训练 ID 更新。
- 原始计划 / 当前计划 / 实际活动分开统计，未记录不等同于没完成。
- 周月复盘、下一周草案、明确恢复确认后的有限进阶。下一周采用后排队，到新周才自动接上；未提前规划时，新周保守延续或减量，不自动进阶。
- 每 30 秒扫描的持久化站内提醒、可选 SMTP 邮件、日 / 周 / 月 / 未记录跟进、安静时段、时区、暂停和跟进语气。
- 导出 JSON、账号及关联数据删除、来源隔离、同源校验、会话保护、过期草案和多页面版本冲突检查。
- AI 调用记账、预算预留、每日限制；模型不可用时回退到有限的规则解析，并在界面注明。

## 数据和生成边界

档案、计划、实际反馈、复盘和对话保存在 SQLite 的每用户状态中；用户输入作为数据使用，模型不能执行 SQL 或绕过计划校验。提醒、邮件状态、会话、验证码、草案和用量各有独立表。

确定性模板负责实际训练内容。AI 整理诉求和提出支持范围内的操作，程序检查时长、恢复间隔和安排冲突。生成模板参考公开的 NHS、NIDDK 和 CDC 一般活动资料；**尚未完成运动专业人士的内容审核**，不能称作已获专业认证的训练处方。首版不提供康复、疾病、孕产或竞技专项方案。身体情况以注意事项和轻量约束纳入计划，普通体检指标异常不阻止生成；急性异常或明确停止运动医嘱时，生成恢复与确认安排，暂停主动训练建议。旧版因非空身体情况而拦截的档案，访问时会自动补出方案。

数据传输应使用 HTTPS。当前没有端到端加密：服务端可读取必要记录。调用 AI 时发送必要档案、当前周计划、近期记录及最近对话；档案整理按钮旁会说明发送行为。提醒邮件不包含训练细节或健康信息。账号删除同步删除本服务数据和用量身份；供应商留存及部署方备份不受该操作直接控制，正式上线前应明确其处理规则。

## 提醒行为

服务进程持续运行时，后台扫描按用户时区执行：

- 训练提醒仅在设定时间后两小时内创建，休息日、已记录训练不创建。
- 用户启用未记录跟进时，在后两小时窗口跟进一次。
- 周一回顾上一周；每月一日回顾上个月。服务关闭期间不运行，不在恢复后补发过期日提醒。
- 安静时段、暂停、身体建议暂停和两周未访问会抑制主动提醒。
- 计划或设置变更会取消尚未发送的旧任务，发送前再次检查用户设置。
- 数据库唯一键抑制重复生成；SMTP 超时可能意味着已经送达，标记为“结果未确认”，不自动重发。
- 不把“已发送”视为“用户已看到”。演示账号不会发送邮件。

本机预览随电脑和服务进程运行。需要全天提醒时，在服务器上用 systemd 持续运行。

## 身体情况与生成策略（2026-11-01 更新）

一般健康风险仍生成训练计划，并在计划页面、调整草案、训练开始前展示遵医嘱提醒，初期使用较轻量安排，风险未明确前不自动进阶。身体情况字段不是医学诊断，关键词仅用于保守的产品分流，不证明活动对个体安全。

出现急性异常、明确停止运动或卧床等限制时，仍提供有结构的恢复与确认计划，暂停主动训练；不使用一条免责声明绕过已知限制。现阶段年龄适用范围与数据保存同意仍需确认。

参考：[NIDDK：从少量活动开始并结合健康专业人士建议](https://www.niddk.nih.gov/health-information/weight-management/tips-get-active/tips-starting-physical-activity)、[Newcastle Hospitals：异常症状与暂停运动](https://www.newcastle-hospitals.nhs.uk/services/newcastle-occupational-health-service/information-for-staff/physiotherapy/self-help-leaflets/exercise-and-your-health-a-guide-to-getting-started/)。
