# 训练生成与评分的知识依据

检索日期：2026-11-07（Asia/Shanghai）。用户所称 ASCM 对应通常写作 **ACSM**（American College of Sports Medicine）。本次只检索机构官网、原始论文及原作者的专业材料；没有以商业健身文章、论坛或模型记忆充当证据。

本文件是知识研究与产品规则映射，不是新增训练处方，也不表示软件、模型或生成计划获得 ACE、ACSM、NSCA 认证。未读取任何真实用户档案。

## 1. 如何使用这些体系

| 体系 | 对生成有用的部分 | 适用人群及限制 |
|---|---|---|
| ACE IFT | 评估起点、关系与依从性；心肺和肌肉能力分别分层；按目标选择训练变量 | 从久坐到有运动基础者；表现目标需评估，不是所有人都固定从最低阶段开始 |
| ACSM FITT-VP 与成人抗阻立场 | 把频率、强度、时间、类型、总量与进阶逐一写清；分开力量、增肌、功率等目标 | 2026 抗阻综述核心是健康成年人，不可直接扩展为术后、急性疼痛或竞技专项处方 |
| NSCA 体能训练设计 | 需求分析、专项性、个体化、渐进超负荷、恢复和有目的的变化 | 体能和运动表现设计框架；具体专项仍需技能、比赛日历和个人训练史 |
| 徒手训练 | 通过杠杆、动作版本、辅助、可控幅度等调节相对阻力 | 徒手不等于新手或低效；但现有动作与环境可能无法提供某肌群足够负荷 |
| 跑步训练 | 基础跑、恢复跑、质量课和长距离的职责分工，先看近期量再放强度 | 健康习惯跑与比赛训练不同；不能仅凭“规律运动”就排竞速间歇 |
| CDC 公共健康活动建议 | 覆盖有氧、抗阻及依从性；用相对强度解释项目选择 | 长期公共健康目标，不是所有人第一周的强制完成清单，也不是进阶专项上限 |

### ACE 的版本问题

2020 更新后的 ACE IFT 是两条可独立组合的三阶段路径：心肺为 Base / Fitness / Performance，肌肉为 Functional / Movement / Load-Speed。旧版材料的四阶段仍在网上，不能把旧版固定周表当作现行唯一标准。一个长期跑者可以有较高心肺能力，同时是抗阻初学者；反之也成立。[ACE_IFT_2020](https://www.acefitness.org/continuing-education/certified/july-2020/7580/the-new-ace-integrated-fitness-training-reg-model-what-has-changed/)、[ACE_IFT_CURRENT](https://www.acefitness.org/about-ace/ace-ift-model/)

## 2. 生成前至少需要什么

以下字段是从体系原则推导的产品输入设计，不是任何机构发布的唯一标准表：

- 目标：习惯/健康、肌肥大、最大力量、耐力、比赛表现等；目标冲突时确定本周期优先级。
- 分项目训练年龄：最近持续做过什么、做了多久、是否中断，而非只问出生年龄或“是否热爱运动”。
- 最近实际训练量：抗阻动作、组数、次数、阻力或可控难度、余力；有氧频率/分钟；跑步近期周公里数、最长单次、配速或体感。
- 技术与环境：熟悉动作、能否控制动作、实际可用器械/最大可用阻力、场地和同伴条件。
- 恢复与限制：近期疲劳、不适和医嘱；睡眠、工作负荷、能坚持的日程。
- 已知与未知：缺数据时输出需要校准的草案，列出待确认项，不能假造工作重量、1RM、心率阈值或旧训练量。

训练年龄应按训练类别记录，而不是把跑龄直接当作力量训练年限。NSCA 的运动员档案材料明确区分这一概念；其青少年示例只能支持定义，不能直接拿青少年年龄/负荷表套成人。[NSCA_TRAINING_AGE](https://dxpprod.nsca.com/education/articles/nsca-coach/using-ltad-to-program-for-a-middle-school-athlete-and-a-high-school-athlete-part-1generating-an-athletic-profile/)

## 3. FITT-VP 落到可执行内容

| 变量 | 计划必须能回答 | 评分可检查的事实 |
|---|---|---|
| Frequency 频率 | 一周练几次，各肌群/专项出现几次，放在哪些日期 | 真实日期、可用日、肌群重叠和跨周安排 |
| Intensity 强度 | 阻力/相对难度如何选，有氧用何种体感或已测指标控制 | RIR/RPE/谈话测试等有无可执行说明；不能凭空生成公斤或个体心率区间 |
| Time 时间 | 热身、主体、组间休息、换侧、收尾各占多久 | 次数×动作时间×每侧，加休息/准备后是否装得进课程 |
| Type 类型 | 为什么选这个项目和这些动作，服务哪个目标 | 动作模式、主要肌群、运动偏好、环境与限制 |
| Volume 总量 | 本周每肌群工作组、有氧分钟、跑步公里数分别多少 | 分开单位、明确热身是否计组、缺数据时不混算 |
| Progression 进阶 | 达到什么条件维持、回退或增加哪个变量 | 有反馈条件，不能按日期自动加重，也不能用随机换动作冒充进阶 |

FITT-VP 定义可核对 ACSM 官方教材公开节选；本次读取的是公开旧版章节，不声称已阅读全文最新版教材。当前 ACSM 书目说明同样强调按特殊人群与实际评估调整处方。[ACSM_FITTVP_EXCERPT](https://www.acsm.org/docs/default-source/publications-files/acsms-exercise-testing-prescription.pdf)、[ACSM_BOOK_OVERVIEW](https://acsm.org/education-resources/books/exercise-testing-prescription/)

## 4. 抗阻、徒手与训练多样性

### 健康成人的目标不能混成一套

ACSM 2026 汇总 137 篇系统综述。较大阻力等变量更有利于最大力量；较高肌群周总组数可优化肌肥大；功率训练则还涉及动作速度等变量。其结果不支持把力竭、复杂器械或复杂周期化当成所有健康成年人的必要条件。[ACSM_RT_2026](https://pubmed.ncbi.nlm.nih.gov/41843416/)、[ACSM_RT_OFFICIAL](https://acsm.org/resistance-training-guidelines-update-2026/)

每肌群约 10 组/周是增肌剂量的证据参考，不是每个人的医学最低量，也不意味着软件应在未知基线时立即补到这个数字。生成器应比较已有耐受量、可用时间与目标，再解释“充分刺激”“时间受限”或“校准草案”。二者不能通过标题互换。[ACSM_RT_INFOGRAPHIC](https://www.acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf)

### 徒手的“进阶”要改变适当变量

ACE 当前徒手设计材料区分：技术训练、体能循环、力量/增肌的目的不同。杠杆、支撑、单侧版本或有效阻力可以改变难度；单纯加快动作、压缩休息，更多体现心肺或耐力负荷，未必改善力量刺激。目标与恢复能力应决定采用何种变化。[ACE_BODYWEIGHT_2026](https://www.acefitness.org/continuing-education/certified/september-2026/9193/body-weight-training-by-design-programming-for-every-fitness-goal/)

如果没有拉力器械，不能把徒手肩胛控制写成与负重划船同等的背部增肌刺激；该项应明确为可用负荷不足，并给补充器械或调整目标的选项。**这是由动作负荷原则推出的产品审查结论，不是上述文章给出的固定动作黑名单。**

### 多样性服务于适应，不以“天天不同”评分

NSCA 原则型设计材料强调先看专项需求、个体能力与环境，再谈渐进和变化。变化要保留足够一致性供能力发展与比较，不能脱离目标随机换课。材料中的换周期例子属于教练实践建议，不能硬编码成每 3–5 周必须换动作。[NSCA_PRINCIPLES](https://www.nsca.com/contentassets/ae95c28e2bdf43c7b69636eacd3e4c72/ptq3.2-3-principle-based_program_design.pdf)

产品可保持一组核心动作，配合互补模式、训练日侧重、阶段内剂量变化和有目的的替代。对进阶者，还要知道已有训练分化和近期表现，不能仅凭“advanced”选一个 A/B/C 模板。

## 5. 有氧与跑步不能只按项目名字定强度

同样跑步、骑行、舞蹈，对不同人的相对强度不同。CDC 给出相对体感与谈话测试的解释；平均心率可以记录，但一次设备平均值无法反推个体最大心率或生理阈值。缺少测量与健康背景时，应使用可理解的体感提示，而不是捏造“精准燃脂区”。[CDC_INTENSITY](https://www.cdc.gov/physical-activity-basics/measuring/index.html)

CDC 成人长期活动建议覆盖有氧与主要肌群抗阻，允许拆成可持续的活动。它适合做公共健康覆盖参考；不能用“未达 150 分钟”直接判新手草案不合格，也不能用“已达 150 分钟”宣称满足半马训练。[CDC_ADULT](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html)

### 跑步量与质量课

B.A.A. 半马资料按经验和比赛目标区分级别，安排不同的基础跑、长跑、节奏/间歇与恢复；其公开表是训练示例，页面也要求按经验选择，不是直接替任何用户完成评估的处方。产品若没有目标距离、比赛日期和近期跑量，应承认只能先提供一般耐力草案。[BAA_HALF](https://www.baa.org/races/boston-half/info-for-athletes/boston-half-training/)

World Athletics 的训练专栏强调速度课不能连续反复堆叠，质量课后要给较轻活动与恢复；力量训练可作为跑者的配套组成。该类原作者经验专栏用于实践设计参考，不能包装成系统综述或保证防伤的证据。[WA_SPEED](https://worldathletics.org/personal-best/performance/speed-training-endurance-runners-benefits-limits)、[WA_STRENGTH](https://worldathletics.org/personal-best/performance/strength-and-conditioning-for-beginning-runners)

### 不把“10%”写成通用安全线

2025 年的一项 5205 跑者观察性队列发现，单次跑距相对过去 30 天最长单次出现较大增加时，与过用伤害发生率升高相关；周比值没有呈现相同关联。它支持审视**单次突增**，不支持“周增量不超 10% 就安全”，也不是可外推到抗阻或骑行的处方阈值。研究主要依赖 Garmin 使用者和自报伤害，存在观察性与人群局限。[RUN_SPIKE_2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12421110/)

若产品目前只记分钟、未记公里数，不能声称已经执行该论文的距离风险模型。现有“连续两段超出本人计划”提醒只能标为产品自定的计划偏差提醒。

## 6. 风险与专业边界

ACE 对慢性伤病的职业范围说明强调，普通私人教练不负责诊断或治疗伤病；既有医嘱、症状与适当转介应影响安排。[ACE_SCOPE](https://www.acefitness.org/resources/pros/expert-articles/6405/how-to-train-a-client-with-chronic-injuries/)

据此，产品可以继续输出带限制的替代方案或恢复安排，但不能把“膝盖不适”自动确诊，也不能推断“另一个部位没写疼就一定能重练”。局部修改应清楚写出适用条件；胸痛、晕厥、明确禁练等与普通稳定风险必须分流。**具体关键词、年龄适用范围、自动回退方式都是产品安全路由，不是 ACSM 诊断算法。**

未充分支持的人群/目标应显式标记：儿童青少年、孕产、术后康复、急性不适、骨质疏松高风险、复杂慢病、专项竞技备赛。不能为了“覆盖广”而让所有人获得同一套健康成人课程。

## 7. 可执行评分规则与依据映射

以下是建议的规则设计；没有修改现有评分代码。证据给原则和参考，最终扣分、封顶、自动采用阈值均需产品单独管理与版本化。

| 规则 ID | 机器可检查内容 | 依据 | 哪部分是产品决定 |
|---|---|---|---|
| FITT_COMPLETE | 课次、强度、时间、动作、周总量、进阶说明是否齐全 | ACSM_FITTVP_EXCERPT | 字段名、缺项分值 |
| TRAINING_AGE_MATCH | 抗阻/跑步经历独立记录；缺基线是否标校准 | ACE_IFT_2020、NSCA_TRAINING_AGE | 进阶层级阈值与问卷项 |
| GOAL_SPECIFICITY | 增肌不能完全无抗阻；专项耐力不能被普通步行模板冒充 | ACSM_RT_2026、NSCA_PRINCIPLES、BAA_HALF | 硬失败与目标适用性封顶 |
| DOSE_TRACEABLE | 组次、有效阻力/余力、主要肌群工作组及来源 | ACSM_RT_2026 | 约 10 组作审查参考；如何标“受限/待校准” |
| TIME_FEASIBLE | 工作、换侧、休息和准备是否装进可用时间 | ACSM_FITTVP_EXCERPT + 处方算术 | 默认每次动作秒数、准备时间与误差容限 |
| BODYWEIGHT_PROGRESS | 徒手版本是否匹配能力，是否有适当难度进退与负荷缺口解释 | ACE_BODYWEIGHT_2026 | 动作库的具体替代关系 |
| RECOVERY_COHERENT | 跨周、同肌群重叠及质量课间隔是否有解释 | NSCA_PRINCIPLES、WA_SPEED | 固定间隔警戒值；不能全局用“相邻力量日必错” |
| RUN_BASELINE | 比赛目标/日期、周跑量、最长单次和质量课设置是否匹配 | BAA_HALF、WA_SPEED | 数据不足时降级为一般耐力，不能猜配速 |
| LOAD_ALERT_HONEST | 区分距/时/组，数据不足时不算风险比率 | RUN_SPIKE_2025 | 当前分钟超计划阈值，不能当论文阈值 |
| NO_RANDOM_VARIETY | 核心动作跨周能比较；替代符合目标与环境 | NSCA_PRINCIPLES | 可接受的变化量与对比周期 |
| SCOPE_EXPLICIT | 不适用目标、医嘱冲突、未知风险、校准范围明确 | ACE_SCOPE、ACSM_RT_2026 | 发布门槛与需专业复核的条件 |
| EVIDENCE_HONEST | 来源适用人群、版本、类型和未知项均可查 | 本次检索方法 | 总分、80 分线和 49/69/79 封顶都不是文献结论 |

### 必须避免的错误评分

- 不因为低复杂度就判新手计划差；不因为条目多就判进阶计划专业。
- 不因无器械就直接判增肌不可能；也不能忽略某肌群可用阻力的现实不足。
- 不把“每肌群 10 组”当所有人必需，不为刷分塞入用户时间装不下的组数。
- 不把安全过渡安排的低目标完成度说成“医学不安全”；计划适用性与医学风险要分列。
- 不把“没有触发关键词/评分通过”当临床安全；不把平均心率、运动次数或游戏进度当骨密度、线粒体或肌肉量测量。
