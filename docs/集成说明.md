# 给 WayWise 共用配置维护者的集成说明

SportsWise 已部署到 https://sportswise.waywise.tech，端口 8500。产品独立 Caddy 片段及 import 已安装，DNS 由用户添加；其他产品代码和总后台未改。

- 产品服务：FastAPI 单 worker，SQLite 默认 data/sportswise.db。
- 注册方式：邮箱验证码，生产配置 SMTP，管理员沿用总品牌邮箱，可用 ADMIN_EMAILS 配置。
- 用量：llm_usage 表沿用 task、actor、prompt_tokens、cached_tokens、completion_tokens、cost、at（UTC）；用户表含 created_at、last_seen_at。actor 是本站用户 ID，不是邮箱。
- 开发与生产 AI 沿用现有配置；用户明确授权生产模型与 SMTP 仅从 InvestWise 复用到 SportsWise，未创建新密钥，凭据只保存在权限 600 的环境文件。
- 采集时可排除 demo=1 的虚构体验用户；预算默认每天 20 元估算上限。
- 服务端保存必要训练明文，默认个人私密；没有沿用 SaveWise 的端到端加密承诺。
- 邮件为独立通知通道，演示空间不发邮件；生产 SMTP 经用户授权配置，登录验证通过，未发送真实测试邮件。
- 端口、Caddy 和服务已就绪。总后台产品采集映射为后续独立接入项。
